# Give an idea a name

Use one colour rule in several places without copying it.

A function receives values through its input names. A calculation gives back a value; a drawing function carries out instructions.

1. **Predict:** What changes if you change the colour rule in just one place?
2. **Try:** Open a starter in Python, JavaScript or Blocks. Start with 25 lights.
3. **Change:** Make a calculation that chooses orange or blue, and a drawing function that paints a marker.
4. **Check:** Change the split from one half to one quarter. Every use of the rule should change together.
5. **Build on it:** Add a second marker using the same drawing function.
6. **Explain:** Point out the supplied values, the function’s input names, and the returned colour.

Each language has four files: `starter`, `solution`, `extension` and `bug`.
Try the task before opening the solution. The bug is deliberate. The broken calculation forgets its else choice. Give colour a value whichever choice runs.
