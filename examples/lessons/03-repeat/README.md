# Repeat a useful action

Paint a changing band of colour on any strip length without copying instructions.

A loop repeats its body once for each position. All those writes make one frame.

1. **Predict:** List the position values for a strip with five lights.
2. **Try:** Open a starter in Python, JavaScript or Blocks. Start with 25 lights.
3. **Change:** Make the red amount grow with position: 60 times position divided by count.
4. **Check:** Try 25, 31, 32, 33 and 100 lights. The end stays below red 60.
5. **Build on it:** Paint every other light blue. Keep the growing red colour on the others.
6. **Explain:** Explain why a loop through the lights is not an animation by itself.

Each language has four files: `starter`, `solution`, `extension` and `bug`.
Try the task before opening the solution. The bug is deliberate. The broken loop takes one step too many and tries to draw outside the strip.
