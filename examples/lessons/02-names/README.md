# Name what changes

Change several lights together without hunting for repeated colour numbers.

A variable is a name for a value. Set a name before reading it.

1. **Predict:** Does changing colour after drawing the first light repaint that light?
2. **Try:** Open a starter in Python, JavaScript or Blocks. Start with 25 lights.
3. **Change:** Give the colour a name, then use that name at both ends.
4. **Check:** Both ends use the same colour. On a one-pixel strip the last instruction wins.
5. **Build on it:** Give the middle light a second colour. Change only one name to try a new theme.
6. **Explain:** Say what colour holds immediately before each drawing instruction.

Each language has four files: `starter`, `solution`, `extension` and `bug`.
Try the task before opening the solution. The bug is deliberate. The broken version changes a colour into a number. Keep a name the same kind of value.
