# Make a choice

Split the strip into coloured sections, with a warning colour near the end.

A condition chooses which instructions to run. Only one side of if/else runs.

1. **Predict:** Which colour appears exactly at the halfway point?
2. **Try:** Open a starter in Python, JavaScript or Blocks. Start with 25 lights.
3. **Change:** Add a red section from three quarters of the strip to the end.
4. **Check:** Use an odd count such as 25. Explain which side gets the extra light.
5. **Build on it:** Add a small white marker at the halfway point.
6. **Explain:** Describe each condition in words before reading the code.

Each language has four files: `starter`, `solution`, `extension` and `bug`.
Try the task before opening the solution. The bug is deliberate. The broken version reverses the comparison. It runs, but paints the sections the wrong way round.
