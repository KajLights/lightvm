# Give the lights instructions

Make the first light orange and the last light blue.

Instructions run in order. Pixel numbers begin at 0.

1. **Predict:** If you paint the same light twice, which colour will you see?
2. **Try:** Open a starter in Python, JavaScript or Blocks. Start with 25 lights.
3. **Change:** Keep the orange light and add a blue light at count minus 1.
4. **Check:** At 1 pixel, blue wins because it is drawn last. At 25 pixels, positions 0 and 24 are lit.
5. **Build on it:** Add a white light halfway along the strip. Try 25 and 100 lights.
6. **Explain:** Point to the instruction that draws first, and explain why the last position needs minus 1.

Each language has four files: `starter`, `solution`, `extension` and `bug`.
Try the task before opening the solution. The bug is deliberate. The broken version uses count as a position. The last valid position is count minus 1.
