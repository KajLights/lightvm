# Make a small installation

Build a lighthouse beam that crosses the ring seam, then explain how it works.

Combine movement, loops, conditions and a named drawing function. Test a change before adding another.

1. **Predict:** When the beam reaches position 0, where do its trailing lights go?
2. **Try:** Open a starter in Python, JavaScript or Blocks. Start with 25 lights.
3. **Change:** Move a three-light beam around the ring. Keep its speed in pixels per second.
4. **Check:** Try 1, 12, 25 and 100 pixels; reverse speed; use a one-second frame delay. Explain overlapping writes on a very short ring.
5. **Build on it:** Add a second beam halfway around the ring, using the same drawing function.
6. **Explain:** Find one loop, one condition, one changing value and one function. Describe an improvement and how you would test it.

Each language has four files: `starter`, `solution`, `extension` and `bug`.
Try the task before opening the solution. The bug is deliberate. The broken version forgets to wrap the trailing lights. It fails when the beam crosses the first pixel.
