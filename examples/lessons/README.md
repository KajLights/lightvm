# Learn with lights

Start with 25 lights in the local preview. A controller is optional. Choose Python, JavaScript or Blocks and stay with it while learning an idea. The other versions let you compare how to say the same thing later.

Allow about 30–45 minutes per lesson; take longer when a prediction needs discussion. Predict, run, change one thing, and explain what happened. Use 5 lights to trace a loop by hand. Try 25, 50 and 100 lights before finishing a project, or 12, 16 and 24 for a ring.

1. [Give the lights instructions](01-first-lights/README.md) — Make the first light orange and the last light blue.
2. [Name what changes](02-names/README.md) — Change several lights together without hunting for repeated colour numbers.
3. [Repeat a useful action](03-repeat/README.md) — Paint a changing band of colour on any strip length without copying instructions.
4. [Make a choice](04-choices/README.md) — Split the strip into coloured sections, with a warning colour near the end.
5. [Make time visible](05-time/README.md) — Make a light blink once per second while the controls stay usable.
6. [Remember movement](06-movement/README.md) — Move a dot at the same speed even when some frames arrive late.
7. [Give an idea a name](07-functions/README.md) — Use one colour rule in several places without copying it.
8. [Make it adjustable](08-controls/README.md) — Move a progress bar without editing and restarting the program.
9. [Remember several values](09-arrays/README.md) — Give each light its own brightness and change one without changing the rest.
10. [Stop when done](10-search/README.md) — Find a free light, including when no lights are free.
11. [Give lights a life](11-fireflies/README.md) — Make small lights appear, fade and leave room for the next ones.
12. [Make a small installation](12-lighthouse/README.md) — Build a lighthouse beam that crosses the ring seam, then explain how it works.

A frame is one finished picture. Drawing inside a loop does not show several separate pictures. Local names start fresh each call; remembered values survive into the next frame. There is no delay or sleep inside the drawing function.

Colours use red, green and blue from 0 to 255. Brightness examples use 0 to 1. Whole pixel positions run from 0 to count minus 1. The examples start dim so their changes are easy to compare. The preview shows a black background where nothing is painted; on a controller, another layer can show through that space.

Use **Next frame** to choose how much time passes. Use **Step through the code** and **Watch a value** to inspect one statement at a time. Only a finished frame changes the displayed lights.

## For teachers

The course files are editable source. Save a local source file before switching examples. Every lesson includes a deliberate bug and an extension, so assessment includes repairing and changing a program. A passing example is only the beginning.
