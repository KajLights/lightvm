# Remember several values

Give each light its own brightness and change one without changing the rest.

An array holds several values. Its position and the value stored there are different things.

1. **Predict:** If the value at position 0 is 0.2, which number says where to draw and which says how bright?
2. **Try:** Open a starter in Python, JavaScript or Blocks. Start with 25 lights.
3. **Change:** Create the brightness array once, change its first value, and read it while drawing.
4. **Check:** Change one entry and then the last entry. Run at 25 and 100 pixels without changing the array length by hand.
5. **Build on it:** Fade every stored brightness value using the time since the last frame.
6. **Explain:** Explain why changing one array entry survives until the next frame.

Each language has four files: `starter`, `solution`, `extension` and `bug`.
Try the task before opening the solution. The bug is deliberate. The broken version forgot to create the array. Create it once in the starting section.
