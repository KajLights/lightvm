# Make it adjustable

Move a progress bar without editing and restarting the program.

A live input can change between frames. A starting setting is read when the program starts.

1. **Predict:** How many lights should be orange at progress 0, 0.5 and 1?
2. **Try:** Open a starter in Python, JavaScript or Blocks. Start with 25 lights.
3. **Change:** Replace the fixed halfway value with the progress input.
4. **Check:** Use the progress control after a frame finishes. Test exactly 0 and 1. A saved value is used again after restart; choose the default in Preview settings & inputs to restore it.
5. **Build on it:** Add a warning colour when progress is at least 0.8. Try a starting setting for the warning point.
6. **Explain:** Explain why an input changes during playback while a setting needs restart.

Each language has four files: `starter`, `solution`, `extension` and `bug`.
Try the task before opening the solution. The bug is deliberate. The broken version uses progress plus 1 as an array position. A progress value is not a pixel position.
