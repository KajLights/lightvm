# Historical portable bytecode experiment

This directory retains the implementation and measurement records from the
standalone bytecode experiment. Its old sample copies, sample runners and
compatibility tests have been removed.

The current experiment uses the normal LightVM firmware and compiler. Follow
[the repository instructions](../../README.md); the only sample sources are the
six Python files in [`examples/animations/`](../../examples/animations/). The editor, command-line tools
and current tests share those files.

[REPORT.md](REPORT.md) and `results/` describe the earlier implementation and its
measurements. Their recorded filenames and hashes refer to that historical run,
not to the current samples or firmware. They are not current deployment instructions.
